# weixin-robot-advanced

微信订阅号聊天机器人：文字菜单互动游戏合集，纯被动回复（5 秒内单条响应），无需客服消息/模板消息权限，个人订阅号即可运行。

## 功能

| 序号 | 游戏 | 玩法 |
|---|---|---|
| 1 | 🌱 农场 | 种植 → 倒计时 → 收获（时间懒惰结算，离线也生长） |
| 2 | 🧙 修仙 | 打坐（离线涨修为）→ 突破境界 → 历练 |
| 3 | 🐱 宠物 | 领养/喂食/玩耍/打工，饱食度衰减 |
| 4 | 📚 答题 | 知识问答 + 成语接龙，连胜加成 |
| 5 | 🃏 图鉴 | 金币抽卡 + 收集图鉴 |
| 6 | 💼 人生 | 打工/升职/存款/取款 |

通用：签到（连续奖励）、邮箱注册/找回（SMTP 验证码）、序号或词语双通道操作、任意界面回复 `0` 回大厅。

## 技术栈

- Node.js ≥ 22.5（使用内置 `node:sqlite`，零原生依赖）
- TypeScript + tsx 直接运行
- Fastify 处理微信回调（明文/兼容/安全模式 AES 加解密）
- SQLite 单文件存储

## 部署

```bash
npm install
cp .env.example .env   # 填入 Token/AppID/EncodingAESKey
npm start              # 监听 PORT（默认 3000）
```

公众号后台「基本配置 → 服务器配置」填入服务器地址（如 `https://yourdomain.com/weixin/reply/`），Token 与 .env 一致即可。建议 nginx 按路径反代到本服务端口。

## 安全

- 所有密钥只放 `.env`（已在 .gitignore 中排除），仓库不含任何凭据
- 消息去重（MsgId + 时间窗）、5 秒超时兜底回复
