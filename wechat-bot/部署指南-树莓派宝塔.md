# 树莓派 · 宝塔部署指南（/www/wwwroot/wechat）

## 前置条件

- 树莓派 **64 位系统**（Raspberry Pi OS 64-bit / Ubuntu arm64）——Node 22 没有 32 位官方包
- 宝塔面板已装，软件商店安装 **Node.js 版本管理器 → 安装 Node 22.x**（项目用到内置 `node:sqlite`，必须 ≥ 22.5）
- 域名解析仍指向树莓派（www.glgxt.cn），SSL 证书可用宝塔 Let's Encrypt 一键申请

## 部署步骤

```bash
cd /www/wwwroot/wechat          # 已上传并解压本项目后的目录
npm install                     # 国内慢可先: npm config set registry https://registry.npmmirror.com
cp .env.example .env
vi .env                         # 填 Token / AppID / EncodingAESKey（与公众号后台一致）
```

## 宝塔 Node 项目配置

面板 → 网站 → Node 项目 → 添加：

- 项目目录：`/www/wwwroot/wechat`
- 启动选项：`start`（对应 package.json 的 `npm start`，实际执行 `tsx src/index.ts`）
- Node 版本：22.x
- 端口：`3000`（与 .env 的 PORT 一致）
- 勾选「守护进程」，首次先手动启动一次看日志无报错

## Nginx 反代（在 glgxt.cn 站点配置里加）

```nginx
location /weixin/ {
    proxy_pass http://127.0.0.1:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
}
```

保存并重载 Nginx。浏览器打开 `https://www.glgxt.cn/weixin/reply/` 应看到「一同学习｜高哩观晓童」状态页。

## 公众号后台

「设置与开发 → 基本配置 → 服务器配置」：

- URL：`https://www.glgxt.cn/weixin/reply/`（不变）
- Token / EncodingAESKey：与 .env 填写一致
- 模式建议「兼容模式」，启用后用任意微信号发一条消息验证欢迎菜单

## 数据与维护

- 数据库：`/www/wwwroot/wechat/bot.db`（单文件，备份它即可全量备份用户数据）
- 日志：宝塔 Node 项目页可看实时日志；常驻问题多为端口占用或 .env 漏填
- 更新代码：覆盖 src/ 后在项目页点「重启」

## 常见问题

| 现象 | 处理 |
|---|---|
| 启动报 `node:sqlite` not found | Node 版本低于 22.5，装 Node 22.x |
| 公众号提示"验证失败" | Token/AESKey 与后台不一致，或 Nginx 反代未生效 |
| 收不到回复 | 面板安全组/防火墙放行 443；确认证书未过期 |
| 答题/种地状态错乱 | 删除 bot.db 重启（会清档，慎用） |
